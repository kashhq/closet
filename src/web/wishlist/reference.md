# Wishlist: reference

Moved out of `AGENTS.md` (#723) so the auto-loaded doc keeps only invariants, gotchas and ownership. Not auto-loaded: read it before changing this area. Where it disagrees with the code or a spec, they win.

- **The agent's suggestions and option groups** (#333, epic #332; the design `docs/plans/2026-10-05-agent-suggestions.md`): a suggestion is a wishlist garment with provenance (`garment.suggested_at` and beside it), an option group one need holding its picks (`option_group`); deciding is feedback, so nothing is deleted, only dismissed. One writer each: `decide` (`decisions.ts`, every decision, through the pure `decideSuggestion`; a page's decision and the need page's read go through `suggestion-actions.ts`'s `makeDecision`/`requireNeed`, and the agent's writes through its `checkSuggestionRoom`, `markSuggestedPick`, `createNeed`, which authorize and refuse themselves, #188), `markSuggestion` (provenance, wishlist only) and `createOptionGroup` (a need, the agent's, #337); the agent's feedback is `feedback.ts`. Lists of things to buy read `wanted` (not set aside), closet reads `inCloset` as ever. The model, its migration from plans (`drizzle/0040`), and its specs: `suggestions.md` beside this file; read it before touching either table's columns.

- **The API** (#194b; `api-routes.ts`, resources in `wishlist-resource.ts`, `src/web/api/AGENTS.md`): `GET /wishlist` is the inbox's sections as one resource, not paged (the needs sort by what every option unlocks: only the whole list knows); `GET /wishlist/needs/{id}` is C; `POST /wishlist/seen` is "New from the agent". Decisions are `makeDecision`'s: `POST /garments/{id}/decisions` (`event` `choose`, `dismiss` with a reason, `undo`), `POST /wishlist/needs/{id}/decisions` (`dismiss`, `undo`), `POST /garments/{id}/returns`; "Bought it" is `POST /garments/{id}/purchases` (`buyWishlistItem`; both fields explicit, null not recorded). A new item is `POST /garments` with `destination: wishlist`; "Bought a different one" is `POST /garments` with `boughtForNeedId` (`postedDestination`, the page's). `GET /garments/{id}/goes-with` (`goesWithCloset`) is the owner's: a share naming the owner is a 403 (coverage EXEMPT, a named test). The agent's own writes stay MCP's (`agentOnly`). `readInbox` reads the switcher only for a `viewerId` (the page's first page).
